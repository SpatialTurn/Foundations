# Foundations: Python and QGIS for Geospatial Work

Source for the **Foundations** module of
[Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/),
published at <https://spatialturn.github.io/Foundations/>.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/). It is the
first module of the curriculum, for complete beginners, and its Setup page is the central setup guide that
the other modules link to.

## Repository layout

| Folder | Contents |

### Data

| File | Contents | Source |
|---|---|---|
| `data/indiana_counties.geojson` | 92 Indiana counties with 2012 population, land area, density and 2016 unemployment | U.S. Census Bureau; U.S. Bureau of Labor Statistics (via plotly datasets) |
| `data/indiana_county_stats.csv` | The same attributes as a plain table, without shapes (for the pandas and join notebooks) | As above |
| `data/indiana_colleges.geojson` | 70 degree-granting Indiana colleges with control and level | NCES IPEDS HD2023 |
| `data/tippecanoe_county.geojson`, `tippecanoe_tracts.geojson` | Tippecanoe County outline and 43 census tracts (`GEOID` as text) | U.S. Census Bureau, 2024 cartographic boundary files |
| `data/tippecanoe_acs_2024.csv` (+ `.csvt` with field types) | ACS 2020-2024 5-year estimates by tract; median income keeps the Census code -666666666 on purpose | U.S. Census Bureau API |
| `data/tippecanoe_tracts_acs.geojson` | The tracts with the ACS columns joined (codes replaced by null) | As above |
| `data/tippecanoe_parks.geojson` | 68 named parks | OpenStreetMap contributors (ODbL) |
| `data/tippecanoe_landcover_2021.tif` | Land cover, 30 m, EPSG:26916, NLCD colors | NLCD 2021 (MRLC) |
| `data/tippecanoe_dem.tif` | Elevation in meters, 30 m, EPSG:26916 | USGS 3D Elevation Program |

The Tippecanoe files are also used by the Data Analysis and Case Studies modules. They are built by
`data_builders/qgis_build_tippecanoe_data.py` in the build scripts (the Census key is read from a local file
and never stored).

Notebooks 4a and 4c also read the Lafayette food store and city limits files from the
[Case Studies](https://github.com/SpatialTurn/CaseStudies) repository.

The notebooks are generated by `fd_python_basics.py`, `fd_data_geo.py`, `fd_raster.py` and `fd_capstone.py` in the
project's build scripts, and
were tested end to end before publishing. The Python notebooks were rewritten for beginners from the
Workshop 2026 Session B notebook, which stays unchanged in its own repository. QGIS screenshots (`fd_qgis_*.png`)
were taken in QGIS 4.0 in the light and dark UI (`figure_builders/qgis_screenshots.py`).
