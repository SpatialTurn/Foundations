New to Python or GIS? Start here. This module teaches the foundations that every other module in the
curriculum builds on: how to run Python notebooks in Google Colab, how to work with tables and charts, how
to handle maps and coordinate systems in Python, and how to make a first map in QGIS. No experience with
programming or GIS is needed.

| Episode | What you will learn | Tools |
|---|---|---|
| Introduction to Foundations | The tools of the curriculum, working in Google Colab, and where to go next | Concepts |
| Python Basics | Running cells, variables, text, lists, dictionaries, decisions, loops and functions | Python notebooks (6) |
| Working with Data | Tables with pandas and charts with matplotlib | Python notebooks (2) |
| Geospatial Python Basics | Map layers with GeoPandas, coordinate reference systems, and attribute and spatial joins | Python notebooks (3) |
| Getting Started with QGIS | Loading data from the web, styling layers, a choropleth map and a finished layout | QGIS |

Each Python notebook takes 15 to 25 minutes, covers one idea, reads its data straight from the web, and
ends with an exercise and its solution.

::::::::::::::::::::::::::::::::::::::::::: prereq

## Prerequisites

- A Google account, to open the notebooks in Google Colab
- A computer where you can install QGIS, for the last episode
- Nothing else: no programming or GIS experience is assumed
